# Network Control dashboard for Home Assistant

I built Network Control to answer the questions I usually check in several dashboards. How fast is the connection? Which devices are on the LAN? Is the Home Assistant host under load? Is DNS blocking working?

The dashboard brings together Speedtest.net history, Nmap Tracker presence, System Monitor, printer supplies, Pi-hole or AdGuard stats, and remote access status. Configure your existing Home Assistant entities to run a speed test, pause DNS filtering, wake a device, or reach router controls from the same view.

You can install it today as a custom repository in Home Assistant Marketplace or HACS. The README includes the full dashboard YAML, optional integrations, and a screenshot with synthetic data.

[Install Network Control and see the dashboard](https://github.com/yanke7/Home-Assistant-Network)

Feedback on different routers, DNS setups, and mobile screen sizes is welcome.
